# keep edges

keep edges

## Usage

``` r
keep_edges(g, filters = list())
```

## Arguments

- g:

  igraph obj

- filters:

  list of filters

## Value

boolean of edges to keep

## Examples

``` r
keep_edges(
   example_network,
   filters = list(
     wij = c(0.5, NA),
     edge_type = "A"
   )
 )
```
