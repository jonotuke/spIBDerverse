# Build the cutoff input for a node or edge attribute

Numeric range Cat: levels

## Usage

``` r
make_cutoff_ui(id, x, g, what = c("node", "edge"), selected = NULL)
```

## Arguments

- id:

  id

- x:

  attribute filter

- g:

  An igraph object.

- what:

  Either `"node"` or `"edge"`.

- selected:

  previous selected values
